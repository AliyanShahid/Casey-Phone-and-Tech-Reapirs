Rather than rebuild the same thing again, the execution plan starts from a clean checklist — and critically, includes an explicit item to **talk through what the website/booking system should actually be before building it again**, instead of jumping straight to a build.

## How to use it
- Open the Notion link above, tick items off as they're done
- Add new rows as new steps come up — don't let it go stale
- When a checklist item represents a real decision or fact worth remembering long-term (not just a to-do), also record it in the relevant department file (01–10) so it doesn't get lost if the checklist item is archived later
- High-priority items are the actual blockers right now — work through those first
