# Casey Phone & Tech Repairs Website

Phase 1 foundation for the Casey Phone & Tech Repairs business website and management system.

## Current Phase

Phase 1: public homepage, application architecture, authentication planning, admin/customer dashboard foundation, and documentation.

This project is saved inside the business planning folder so future website changes can be tracked alongside the business plan.

## Run Locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Important Windows Note

The parent folder contains an ampersand in its name. Previous Node tooling had issues in this path. If package installation or dev server commands fail, keep this source folder here for tracking, but run a working copy from a clean path such as `C:\Users\aliya\Claude_n8n\casey-website`.
